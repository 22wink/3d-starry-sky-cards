# 3D 星空卡片轮播

一个基于 Three.js 的 3D 交互式卡片轮播系统，具有星空背景、惯性滚动、卡片交互等丰富功能。

## ✨ 功能特性

### 🎨 视觉效果

- **3D 卡片轮播**：卡片在 3D 空间中按斐波那契螺旋排列，形成优美的球面分布
- **星空背景**：动态生成的 10,000 颗星星，营造沉浸式体验
- **发光边框**：卡片具有多层发光边框效果，悬停时动态高亮
- **平滑动画**：所有交互都采用缓动函数，提供流畅的用户体验

### 🖱️ 交互功能

- **鼠标拖拽旋转**：拖动鼠标可以旋转整个 3D 场景
- **惯性滚动**：快速拖拽后松手，场景会继续旋转并逐渐停止（物理惯性效果）
- **滚轮缩放**：使用鼠标滚轮可以缩放场景，调整观察距离
- **卡片点击**：点击卡片可以打开详情模态框
- **卡片悬停**：鼠标悬停在卡片上时，卡片会放大并显示发光边框
- **智能点击检测**：防止拖拽后误触点击，提升交互体验

### 📱 模态框功能

- **卡片详情展示**：点击卡片后显示大图预览
- **下载功能**：支持下载卡片图片
- **收藏功能**：可以收藏/取消收藏卡片
- **优雅的动画**：模态框打开和关闭都有平滑的动画效果

## 🛠️ 技术栈

- **Three.js**：3D 图形渲染引擎
- **原生 JavaScript**：无框架依赖，轻量高效
- **Canvas API**：用于绘制卡片内容和星空背景
- **CSS3**：样式和动画效果

## ⚙️ 参数配置

### 惯性滚动参数

在 `app.js` 中可以调整以下参数：

```javascript
// 速度历史记录长度（用于平滑计算）
const maxHistoryLength = 3;  // 默认：3帧

// 摩擦力系数（0-1，越小衰减越快）
const friction = 0.95;  // 默认：0.95，推荐范围：0.9-0.98

// 最小速度阈值，低于此值停止惯性
const minVelocity = 0.001;  // 默认：0.001
```

### 点击检测参数

```javascript
// 拖拽距离阈值（像素），超过此值认为是拖拽而非点击
const DRAG_CLICK_THRESHOLD = 5;  // 默认：5像素

// 拖拽结束后忽略点击的时长（毫秒）
const CLICK_IGNORE_DURATION = 150;  // 默认：150毫秒
```

### 场景参数


## 🎯 核心功能说明

### 1. 惯性滚动系统

惯性滚动通过以下机制实现：

1. **速度记录**：在拖拽过程中记录最近 3 帧的速度
2. **速度计算**：使用平均速度作为初始惯性速度
3. **摩擦力衰减**：每帧应用摩擦力系数，使速度逐渐减小
4. **自动停止**：当速度低于阈值时自动停止

### 2. 智能点击检测

为了防止拖拽后误触点击，系统实现了：

1. **距离检测**：记录拖拽总距离，超过阈值视为拖拽
2. **时间窗口**：拖拽结束后 150ms 内忽略点击事件
3. **状态管理**：通过 `justFinishedDragging` 标志控制点击行为

### 3. 卡片排列算法

卡片使用斐波那契螺旋算法在球面上排列：

```javascript
const goldenRatio = (1 + Math.sqrt(5)) / 2;
const y = 1 - (i / (numCards - 1)) * 2;
const radiusAtY = Math.sqrt(1 - y * y);
const theta = (2 * Math.PI * i) / goldenRatio;
```

这确保了卡片在 3D 空间中的均匀分布。

### 4. 动画系统

项目包含一个完整的动画管理器：

- **缓动函数**：`easeOutCubic`、`easeInOutCubic`
- **动画队列**：支持多个动画同时运行
- **自动清理**：动画完成后自动移除

## 🐛 常见问题

### Q: 图片无法加载？

A: 检查图片 URL 是否可访问，确保支持 CORS。

### Q: 惯性滚动太快/太慢？

A: 调整 `friction` 参数，值越小衰减越快。

### Q: 点击卡片无响应？

A: 检查是否在拖拽后的忽略时间窗口内，或调整 `CLICK_IGNORE_DURATION`。

### Q: 性能问题？

A: 减少星空数量或卡片数量，或降低几何体复杂度。
